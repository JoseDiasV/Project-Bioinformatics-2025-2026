## EN-CSLR ensembled ML model for protein secondary structure prediction

This repository contains code and data for building and running a ML model for protein secondary structure prediction. The project works with protein sequences, PSSM profiles, and curated datasets, and supports both local execution and execution on the MetaCentrum computational cluster.

---

## Dataset

The dataset used in this project is stored in:

`astral_cull_DATA/`

It contains a curated and culled protein sequence, secondary structure and PSSM dataset derived from the ASTRAL database and is used for training and evaluation of the integrated model.

---

## Integrated Model

The main model implementation is located in the `integrated_model/` directory:

- **main_incorporated_model.py**  
  Main entry point for running ensemble EN-CSLR model.

- **models_pssm.py**  
  Containes definition of all custom ML models used - CNN, LSTM and Softmax classifier.

- **SS_db.py**  
  Utilities for handling secondary structure databases.

- **header.py**  
  Definiton of functions used for data loading, model training, extraction of features, ensemble calc and others.

---

## Execution

Submit the main using:

`python3 main_incorporated_model.py`

The script has to be run in the same folder as input PSSMs and the input db file. It has to be physically stored in the same directory as support python scripts.

## Running on MetaCentrum

The script `_run_gpu_job.sh` is a PBS job submission script used for running the model on the MetaCentrum HPC cluster.

Submit the job using:

`qsub _run_gpu_job.sh`


The script requests GPU resources and runs the integrated model remotely.
